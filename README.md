# Clinical Decision Support System (CDSS) for Type 1 Diabetes Mellitus

> An intelligent decision support system to assist clinicians with continuous glucose monitoring (CGM) analytics and personalized insulin dosing decisions.

## Project Overview
This repository contains the problem formulation, software requirements, user stories, and architectural design for a Clinical Decision Support System (CDSS) integrated with Electronic Health Record (EHR) platforms for Type 1 Diabetes Mellitus (T1DM) management.

## Problem Statement
Managing Type 1 Diabetes requires complex clinical decisions regarding insulin dosing, basal rates, and carbohydrate ratios. Existing clinic EHRs display raw Continuous Glucose Monitor (CGM) and pump logs without automated pattern recognition, making it difficult for clinicians to spot dangerous trends like nocturnal hypoglycemia during brief consultations. This project proposes a CDSS extension to clinic EHRs that automatically analyzes CGM metrics to deliver real-time insulin dosage adjustments and early risk warnings.
